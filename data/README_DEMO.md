# Synthetic gasification demonstration dataset

`demo_gasification.csv` is a **hand-authored synthetic demonstration dataset**, not a research dataset, not extracted from scientific literature, and not valid evidence for gasification mechanism or parameter optimization. Values are illustrative only; correlations are not scientific findings.

Columns:
- `temperature_C`: gasification temperature, °C
- `steam_fuel_ratio`: steam/fuel ratio (illustrative; convention not standardized)
- `hydrogen_vol_pct`: hydrogen fraction of syngas, vol%
- `total_syngas_yield_Nm3_per_kg`: total syngas volume per kg feedstock, illustrative Nm³/kg

To analyze real experimental data, place a vetted, legally shareable CSV in the same directory, use a safe file stem as dataset ID, and document source, units, method, missing values, and study identity separately.
